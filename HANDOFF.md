## ОПУБЛИКОВАНО В GOOGLE PLAY — 31 августа 2026

**https://play.google.com/store/apps/details?id=cz.konsalting.vektor** — страница живая, проверено
анонимным запросом (HTTP 200, отдаёт «Vector — cycling beacon»). Production: versionCode 8 / 1.0.4,
176 стран, витрина EN+RU с промо-роликом.

**Поиск внутри Play подтягивается с задержкой** — от нескольких часов до пары суток, и новое приложение
без установок и отзывов стоит в выдаче далеко. По прямой ссылке всё работает сразу.

Что потребовал Play сверх нашего чек-листа (для следующих релизов):
- **Страны/регионы** у Production трека — их не было вовсе, и именно это держало кнопку отправки серой.
- **Декларация «Разрешения на использование активных служб»** (Android 14+, раз объявлен
  `FOREGROUND_SERVICE_LOCATION`): задача **Навигация**, текст §3 `docs/PLAY-LISTING.md`,
  видео https://www.youtube.com/watch?v=cgbiE_2xiUE
- **Декларация рекламного идентификатора** (targetSdk 33+) — живёт внутри мастера «Безопасность данных»,
  который надо пройти все 5 шагов и сохранить, иначе числится неполным. Ответ «Нет» проверен по коду.
- Предупреждение «нет файла деобфускации» — безобидное, следствие выключенного R8.
- Первый релиз нельзя создать через API со статусом `completed`: пока приложение не опубликовано, Play
  принимает только `draft` («Only releases with status draft may be created on draft app»). Отсюда флаг
  `--draft` у `promote`. Для последующих обновлений работает обычный `completed`.

## Сборка подписанного AAB локально

Нужны: JDK 21 (Temurin), Android SDK (`%LOCALAPPDATA%\Android\Sdk`, cmdline-tools + platforms;android-36 +
build-tools;36.0.0), `android/keystore.properties` (по `.example`; ключ в `vektor-keys`, пароль в
README-credentials там же — **в репозиторий не попадает**).

```powershell
npm run build ; npx cap sync android --inline
cd android ; .\gradlew.bat bundleRelease   # → app/build/outputs/bundle/release/app-release.aab
```

Заливка в Play (нужен `C:\Users\User\play-api-key.json`, тоже вне репозитория):

```powershell
python scripts/play-publish.py upload --aab <path.aab> --track internal --commit
```
