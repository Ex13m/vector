# Vector — конвейер «один ролик в неделю на автомате»

**Что изменилось относительно вводной (проверено 17.09.2026):** Kling — 19,2 кредита (мёртв: даже 5 с 720p = 30–45 кр.); Higgsfield — **659 кредитов на плане Ultimate** (живой, не «пустой»); Replicate — пуст (402 = нет платёжного метода); Sora 2 закрывается 24.09 — исключена. В каталоге коннекторов Claude есть официальный **Metricool MCP** (createScheduledPost), Buffer — только как custom connector.

---

## 1. Архитектура

```
[Владелец, опционально]  телефон на руле/груди, вертикально, 1–2 мин  →  папка Google Drive «vector-raw» (автозагрузка)
            │
[Cloud routine Claude Code, еженедельно, Пн 06:00 CET]  «мозг»
   1. читает очередь идей (content-plan.yaml) и таблицу episodes в Supabase → берёт следующую невыпущенную
   2. есть новое сырьё? → скачивает; нет → берёт клипы из библиотеки (реальные + AI b-roll)
   3. пишет сценарий недели: хук-титр, 3–4 реплики голоса приложения из банка, подпись, теги
   4. запускает pipeline.py (детерминированная часть, см. ниже)
   5. QC: 4 кадра из мастера смотрит сам (дубли объектов, статика, артефакты) + авто-метрики; при браке — один повтор
   6. createPost ×3 в Buffer с dueAt = Вт 18:00 CET; проверяет id постов в ответе
   7. пишет строку в episodes, шлёт письмо (Gmail connector): превью-ссылка, id постов, dueAt / причина ошибки
            │
[pipeline.py — Python + ffmpeg, один код для облака (Ubuntu, setup script: apt install ffmpeg) и Windows]
   стабилизация (vidstab 2 прохода) → выбор 15-с окна с максимумом движения → концепт-монтаж
   (хук 0–2 с / POV 10 с / «пруф» 5 с: телефон в кармане, экран чёрный / CTA 5 с) → голос из банка WAV
   (word-timings из JSON) → ASS-субтитры 2–4 слова/страница с подсветкой → лого, CTA-титр, плашка AI (если есть
   AI-сцены) → amix + loudnorm −14 LUFS → 1080×1920@30 H.264 yuv420p +faststart → upload в Supabase Storage
   (public bucket, video/mp4) → Buffer GraphQL createPost
            │
[Buffer Free]  YouTube Shorts + Instagram Reels + TikTok — публикует сам, аудиты площадок у него пройдены
```

**Кто и почему:**

| Звено | Что делает | Почему именно так |
|---|---|---|
| Владелец, один раз (≈2–3 часа) | аккаунты TikTok/Instagram, OAuth в Buffer, API-ключ, карта в Replicate, банк голоса с телефона, 2–3 поездки на библиотеку | регистрацию и OAuth площадки разрешают только человеку; голос приложения существует только на Android-устройстве |
| Владелец, еженедельно (0–2 мин, необязательно) | нажать «запись» на велосипеде | реальные кадры — единственное, что не требует метки deepfake и не режется фильтрами «AI slop»; если не снял — конвейер берёт библиотеку |
| Cloud routine (Pro/Max) | творческая часть, ветвление, QC, отчёт | не зависит от включённого ПК; connectors (Higgsfield, Supabase, Gmail, Drive) доступны из коробки |
| pipeline.py | всё детерминированное | ffmpeg/ASS предсказуемы, бесплатны, без облачных кредитов |
| Supabase | хостинг mp4 + таблица состояния | Buffer/Instagram требуют постоянный публичный URL с video/mp4; коннектор уже подключён |
| Buffer | публикация | единственный планировщик с API на бесплатном тарифе, снимает private-лок YouTube и SELF_ONLY TikTok |

Окно вето: между рендером (Пн утро) и публикацией (Вт вечер) владелец **может** удалить пост в Buffer, но не обязан — конвейер работает без него.

## 2. Два варианта

| Критерий | А) Полный AI (Kling/Seedance/H3) | Б) Владелец снимает 1–2 мин, остальное автомат |
|---|---|---|
| Стоимость/мес | $0 пока живут 659 кр. Higgsfield (≈22–25 роликов Kling 3.0/H3), далее Replicate: H3 $1,20 или Seedance Mini $1,35 за 15 с, с 1 повтором ≈ **$10–12** | ffmpeg/Python бесплатно, Gemini-анализ ≈$0,01, AI-вставка 5 с ≈$0,40 → **$0–2** (+$6 если музыка ElevenLabs) |
| Качество | топ-Elo модели, но «синтетический велосипедист» узнаваем; экран телефона и карта приложения — выдумка | настоящая дорога, настоящий телефон, настоящий голос TTS — то, что услышит пользователь |
| Доверие к платному ($4,99) приложению | ниже: 39% потребителей меньше доверяют брендам за AI-контент; TikTok даёт пользователям ползунок «меньше AI» | выше; лицо владельца на 2–3 с — то, что YouTube сейчас поднимает |
| Риски площадок | YouTube опускает безликие AI-каналы; «inauthentic content» при однотипных роликах; обязательные метки везде | минимальные; метка нужна только на неделях с AI-вставкой |
| Маркировка / EU AI Act | фотореалистичный велосипедист = deepfake по ст. 50 → видимая плашка + флаги на всех площадках | не нужна, кроме недель с фотореалистичной AI-вставкой |
| Нагрузка на владельца | 0 | 0–2 мин/нед, необязательно (fallback на библиотеку) |
| Надёжность конвейера | зависит от API генераторов и кредитов; брак 20–30% требует повторов | ffmpeg детерминирован; риск — плохое сырьё (дождь, тряска) → авто-выбор окна + библиотека |

**Рекомендация: Б с автоматическим откатом в А.** Причины: (1) главная фича — голос из кармана при выключенном экране — на экране не видна, её показывает только реальный кадр «телефон уезжает в карман, голос продолжает»; (2) дешевле на порядок; (3) не попадает под фильтры AI-slop и AI Act; (4) не зависит от еженедельной съёмки: после 2–3 поездок в библиотеке 15–20 реальных клипов + 15–18 AI b-roll, сгенерированных **сейчас** на сгорающие кредиты Higgsfield (подписочные кредиты обнуляются в конце цикла — это надо превратить в постоянный актив, а не терять). AI используется только как вставки (крупный план телефона в кармане, абстрактный циферблат, «карта с высоты»), а не как основа.

## 3. Публикация

| Площадка | Автомат сегодня? | Путь | Разовые шаги | Срок |
|---|---|---|---|---|
| YouTube Shorts | **да** | Buffer (канал «Vector Beacon» есть) | OAuth-подключение канала в Buffer | 5 мин |
| Instagram Reels | **да** | Buffer, Instagram Login (Facebook Page не нужна) | создать аккаунт, переключить в Professional (Creator), OAuth в Buffer | 15 мин |
| TikTok | **да** | Buffer (обычный аккаунт подходит; флаг isAiGenerated) | создать аккаунт, OAuth в Buffer | 10 мин; Business-статус нужен только ради ссылки в bio, у частника подтверждение бизнеса может не пройти |
| Facebook Reels | можно | своя Page + Graph API (единственный с нативным расписанием) | Page, Meta-app | не делать — ценность для велонавигации нулевая |

Общее: Buffer Free = 3 канала, 10 постов в очереди/канал, API-ключ на любом тарифе (3000 запросов/30 дней), дневные лимиты YouTube 10 / Instagram 50 / TikTok 25. Подключение к Claude: custom connector `https://mcp.buffer.com/mcp` (OAuth) **или** API-ключ как API credential среды routine — второе надёжнее для скрипта.

**Прямые API — почему нет:** YouTube Data API без аудита проекта → все ролики private (форма аудита бесплатна, ответ — недели, SLA нет); TikTok Content Posting без аудита → SELF_ONLY, аудит с демо-видео — недели; Instagram Graph API — работает на Standard Access без ревью, но требует Meta-app, refresh long-lived токена каждые 60 дней и публичный URL — держать как резерв.

**Резервы:** Metricool (официальный коннектор в каталоге Claude, free 20 постов/мес, 1 бренд — поддержку видео через MCP проверить одним постом); Zapier MCP (уже подключён: YouTube + Instagram, TikTok отсутствует, 100 задач/мес); Upload-Post Free (10 загрузок/мес, YT+IG, TikTok — платно). Higgsfield `tiktok_publish` — не проверен, не полагаться.

**Руками навсегда:** создание аккаунтов и OAuth; Related video в YouTube Studio (через API не ставится — единственный кликабельный путь из Short на длинное видео со ссылкой); ответы на комментарии (автоответы через API — риск выглядеть ботом, минимум — закреплённый комментарий «Vector Beacon в Google Play», его ставит Buffer как firstComment на Instagram, на YouTube/TikTok — руками); плейлист в карточке Google Play (Premium growth tools, скорее всего недоступен, проверить в Grow → Store presence).

## 4. Контент-план — 8 идей на два месяца

Мастер на английском (глобальный Android + CTA через поиск в сторе); банк голоса писать в EN/RU/DE — RU/DE-версии потом бесплатны. Нумерация = порядок выпуска, структура намеренно разная (защита от «inauthentic content»).

1. **Хук:** титр «Screen OFF. Still navigating.» + голос «Target at 3 o'clock, 8 kilometers» на 0,4 с → **показ:** POV дорога, телефон уезжает в карман, экран гаснет, голос продолжает → **CTA:** «Vector Beacon · Google Play · 5 rides free».
2. **Хук:** «No turns. No map. Just a direction.» → анимированный циферблат поверх реальной дороги, стрелка на «3 часа», голос называет направление и дистанцию → CTA «Search: Vector Beacon».
3. **Хук:** «Lost in the forest?» (лесной POV) → постановка «Back to start», голос ведёт к точке старта, титр «beacon back to where you began» → CTA.
4. **Хук:** лицо владельца 2 с: «I stopped looking at my phone on the bike. Here's why.» → POV + голос, 3 реплики → CTA (единственный ролик с реальным человеком в кадре — важен для YouTube).
5. **Хук:** «5 rides free. Then $4.99 once. No subscription. No ads.» → запись экрана scrcpy: цель в 2 тапа, старт, кнопка питания — экран чёрный, звук идёт → CTA.
6. **Хук:** «12 o'clock = straight ahead» → мини-урок: три примера (12, 3, 9 часов) на трёх реальных отрезках, голос + субтитры → CTA.
7. **Хук:** «Earbuds in. Phone in the jersey pocket.» → крупный план наушника, карман, дорога, голос → CTA. (Перед выпуском проверить, что BT-сценарий работает на текущей сборке.)
8. **Хук:** «City. Trail. Same app.» → 2 контрастных POV из библиотеки, один и тот же голос, титр «works with the screen off» → CTA.

Что говорим только правду: работает с выключенным экраном; направление по циферблату + дистанция; маяк обратно к старту; 5 поездок бесплатно, $4,99 разово, без подписки и рекламы. **Не говорим:** цифры про батарею, точность GPS, «работает офлайн», «лучше Google Maps», отзывы вымышленных пользователей.

## 6. Первая неделя — пошагово

**День 1 — доступы (владелец, ≈1 ч).** Создать TikTok и Instagram (→ Professional/Creator). Buffer Free: подключить YouTube «Vector Beacon», Instagram, TikTok; создать API-ключ. Replicate: добавить карту (снять 402). Higgsfield: `balance`/billing — уточнить статус Ultimate. Supabase: bucket `media` (public) + таблица `episodes(week, idea_id, status, master_url, buffer_ids, ai_used)`. Netlify: три редиректа `/go/{yt,tt,ig}` → `play.google.com/...&referrer=utm_source%3D{yt|tt|ig}%26utm_campaign%3Dweekly`; вписать в bio всех трёх аккаунтов и в About канала.

**День 2 — банк голоса и экрана (владелец, ≈45 мин).** На телефоне TTS Util (F-Droid): движок Google, голос по умолчанию для en-US/ru-RU/de-DE, текстовый файл с 40–60 фразами в формате buildPhrase (12 позиций циферблата × 3–4 дистанции, «Go», «You have arrived», «Target ahead») → WAV. Альтернатива: `scrcpy --no-video --no-control --record=phrase.opus` при нажатии VOICE в приложении. Плюс `scrcpy --no-playback --no-control --record=scene.mp4 --time-limit=30` — 8–10 экранных сцен (карта, цель, старт, нажатие питания). Word-timings для банка один раз faster-whisper → JSON.

**День 3 — сырьё (владелец, 1 поездка 15–20 мин).** Телефон вертикально на груди/руле, стабилизация включена, 1080p30; отдельно 3–4 крупных плана: телефон в карман, экран гаснет, наушник. Автозагрузка в Drive «vector-raw» (доступ по ссылке — так облачная routine скачает `gdown`).

**День 4 — AI-библиотека (агент, кредиты Higgsfield).** 15–18 клипов 9:16 × 15 с через `generate_video` (Kling 3.0 или H3, preflight `get_cost`): крупный план телефона в кармане джерси, абстрактный циферблат, дорога с высоты, дождь/город/лес; в промптах «exactly ONE cyclist», движение камеры в каждом; QC по кадрам; ≈450 кр., остаток на повторы. Всё в Supabase `library/`.

**День 5 — репозиторий `vector-media` и локальный прогон (агент + владелец смотрит результат).** pipeline.py, ASS-генератор, шаблон титров (шрифт с кириллицей, лого, safe-zone), content-plan.yaml с 8 идеями, клиент Buffer GraphQL. Прогон на Windows: мастер + preview с safe-zone. Ручной QC первого ролика — единственный раз.

**День 6 — облачная routine.** Environment: setup script `apt install -y ffmpeg python3-pip && pip install librosa gdown`; network: Custom allowed domains (api.buffer.com, *.supabase.co, api.replicate.com, replicate.delivery, drive.google.com, CDN Higgsfield); API credentials: Buffer key, Replicate token, Supabase service key. Schedule: weekly, Пн 06:00 CET. Промпт заканчивается проверкой ответа Buffer и письмом. Пробный запуск `/fire` с dueAt через 2 часа → проверить пост в Buffer и публикацию.

**День 7 — контроль.** В Play Console → «Ads and referrals» должны появиться UTM source `yt/tt/ig`. Закрепить комментарии с названием. Формула еженедельной оценки в отчёте: UTM-визиты / просмотры; порог для смены формата — 4 недели подряд ниже 0,3%.

## 7. Чего не обещать

- **«Ноль участия» = только после недели настройки.** Аккаунты, OAuth, банк голоса, первая съёмка — руками. Дальше 0 мин при наличии библиотеки; свежая съёмка — по желанию.
- **TikTok напрямую нельзя:** без аудита приложения всё SELF_ONLY. Только через аудированный сервис (Buffer/Metricool). YouTube напрямую — private без аудита. Если Buffer заблокирует аккаунт или изменит Free — переезд на Metricool/Zapier (день работы).
- **Ссылок нет нигде:** Shorts — описание и комментарии некликабельны; TikTok — только bio (1000 подписчиков или Business); Instagram — bio, ссылка в Reel от $44,99/мес. QR в TikTok лишает рекомендаций. CTA = название для поиска в сторе.
- **Метки обязательны:** YouTube «altered/synthetic» и `isAiGenerated` для фотореалистичных AI-сцен, TikTok `is_aigc`, Instagram `isAiGenerated`; по EU AI Act ст. 50 (действует с 02.08.2026) владелец — deployer: фотореалистичный синтетический велосипедист = deepfake → видимая плашка «AI-generated» с первой секунды. Анимация/циферблат/титры — не требуют. C2PA-метаданные ffmpeg'ом не стрипать — санкции за нераскрытие тяжелее.
- **Никаких AI-«довольных пользователей»** и UGC-актёров — маскировка коммерческого умысла (UCPD) + deepfake.
- **Один ролик в неделю — поддержание присутствия, не машина установок.** Плейбуки рассчитаны на 3 поста в день; на 10 000 просмотров реалистично 5–50 переходов и 1–8 установок. Успех считать по UTM-визитам в Play Console, не по просмотрам.
- **52 ролика по одному шаблону** = «inauthentic content» на YouTube — конвейер обязан ротировать структуру (в плане это заложено).
- **Routines — research preview**, лимиты могут меняться; зелёный статус ≠ публикация — поэтому проверка id постов и письмо обязательны.
- **Кредиты:** Higgsfield сгорают в конце цикла (потратить на библиотеку сейчас); Kling MCP по умолчанию ставит 4K (150 кр. за 5 с) — не трогать; Replicate биллит по карте постфактум; цена Wan 3.0 на Replicate, вероятно, промо.
- **Не обещать в роликах:** экономию батареи в цифрах, точность GPS, офлайн-режим, сравнения с Google Maps — только то, что приложение действительно делает.
