# DEVLOG — Vector promo

## 2026-08-25/26 — производство v1
- Якорь героя: `google/nano-banana-2`, 1 генерация (15.7 с). Без брендов, бренд-палитра. Принят с первого раза.
- Клипы: `bytedance/seedance-2.0`, R2V от якоря, 5 с / 720p / 16:9 / `generate_audio: true`.
  - 01-forest — принят сразу.
  - 02-pocket — v1 брак: старт с места (замечание пользователя) → переписан motion-промпт («никогда не останавливается,
    колёса не перестают крутиться, земля летит в моушн-блюре») → v2 принят. v1 в `archive/`.
  - 03-ridge — v1 брак: педалит на месте (камера отъезжала с его скоростью) → «камера ОТСТАЁТ, дистанция растёт,
    пыльный шлейф» → v2 принят. v1 в `archive/`.
  - 04-ford, 05-night — приняты сразу. 05 с первой попытки упал на таймауте Replicate — перезапуск помог.
- Плашка: сгенерирована локально (PIL + ffmpeg), 3 с.
- Звук: `google/lyria-2` (32.8 с) + 5 реплик `minimax/speech-02-hd`, дорожка собрана по таймкодам через `adelay`.
- Монтаж: `assemble.py` — нормализация 1280×720/24fps → concat → микс (эмбиенс 0.35 / музыка 0.55 / закадр 1.6) → loudnorm −14 LUFS.
- Апскейл: `topazlabs/video-upscale` → 4K/60. Грабли: модель требует ПУБЛИЧНЫЙ URL с расширением —
  ссылка Replicate Files API не подошла (`source.container is required`), решилось раздачей мастера с Netlify.
- Сайт: видео-герой на `/landing.html` (autoplay без звука + кнопка Sound on → версия с озвучкой),
  веб-версии пережаты из 4K-мастера.

**Расход:** ~9 генераций Replicate (1 картинка, 6 видео-заходов, 1 музыка, 5 TTS, 1 апскейл 4K).
Точные суммы — в billing Replicate.
